# Agent knowledge — where it lives

Standing knowledge about this machine and its user lives in the PAZRAS tree.
Read `~/06_SYSTEM/CONTEXT.md` (the router) and stop at the first row
that answers; for a fact rather than a folder,
`~/06_SYSTEM/memory/knowledge/INDEX.md` lists every leaf with one line and its
trigger terms. Knowledge about one *project* stays in that project's own
`CLAUDE.md`/`AGENTS.md`.
